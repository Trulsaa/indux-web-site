# INDUX Website

Publisert på GitHub Pages: https://trulsaa.github.io/indux-web-site/

## Publiser ny versjon

```bash
git add index.html
git commit -m "Beskriv endringen"
git push
```

Siden oppdateres automatisk innen 1–2 minutter etter push.

## Eget domene

1. Gå til [repo-innstillinger → Pages → Custom domain](https://github.com/Trulsaa/indux-web-site/settings/pages)
2. Skriv inn domenet ditt (f.eks. `indux.no`)
3. Sett opp en CNAME-record hos DNS-leverandøren din som peker til `trulsaa.github.io`
